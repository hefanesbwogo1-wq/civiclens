# CivicLens

CivicLens is a political intelligence platform for tracking public mentions, managing politician profiles, and monitoring sentiment across social channels.

### Features
- **Mention Tracking** - Real-time detection of keywords / politician names
- **Dashboard** - Overview of mentions, sentiment, and activity
- **Profiles** - Manage politician / public figure profiles
- **Subscriptions** - User subscription & billing management
- **Admin Panel** - User and system management
- **Auth** - Login / Register with secure backend
